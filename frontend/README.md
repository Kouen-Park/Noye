# Noye Frontend

The Next.js user interface for Noye. See the [repository README](../README.md)
for what Noye is and how the whole system fits together.

Built with Next.js 16, React 19, TypeScript, Tailwind CSS 4, and the App
Router.

## Getting started

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The frontend expects the FastAPI backend on `http://127.0.0.1:8000`. Start it
first — see the repository README's Development section.

## Layout

```text
frontend/
├── src/
│   └── app/          # App Router pages, layouts, and global styles
└── public/           # Static assets
```

The home page lives at `src/app/page.tsx` and the root layout at
`src/app/layout.tsx`. Note the `src/` prefix: this project was scaffolded with
the `src` directory option, so paths in general Next.js documentation are one
level shallower than the real ones here.

## Commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server with hot reload |
| `npm run build` | Production build, includes type checking |
| `npm run lint` | ESLint |

## Notes

`AGENTS.md` in this directory is generated by `next dev` and recreated on every
run, so it is committed intentionally. It warns that Next.js 16 changed APIs
and conventions relative to older versions — read the guides in
`node_modules/next/dist/docs/` rather than relying on memory of earlier
Next.js releases.

Noye is a local-first application and is not deployed to a hosting platform.
The planned distribution path is a Tauri desktop build, not a web deployment.
